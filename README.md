# UCCS-Resource-Locator
An independent prototype developed as part of student assistant work with the UCCS Bachelor of Innovation Department.  The website is designed to help students discover and access UCCS and Pikes Peak region resources through a centralized, searchable directory.

## Project Status: Prototype — Under Review and Development
Individually auditing resource descriptions, changing phrasing where needed, manually confirming phone numbers/email contact info.

## Current Resource Count: 
178 Resources, both campus and local Pikes Peak region

## Note: 
This project is *not currently an official UCCS website nor yet approved by UCCS DEPA. Resource information is actively being reviewed for accuracy.
